# README - science-based-thresholds

## 快速使用

当你需要设定**任何阈值**时（规则触发、告警阈值、性能阈值、缓存大小等），参考 `SKILL.md` 中的五步法：

1. **收集数据** - 当前规模和趋势
2. **引用理论** - 速查表中的科学依据
3. **对比实践** - 理论与实际的偏差
4. **设定缓冲** - 提前介入（理论值 × 0.75）
5. **持续验证** - 每季度复审调整

## 核心要点

### 三层防线
```
理论值 → 中间值（理论×0.75） → 紧急值（理论×1.25）
   ↑         ↑                    ↑
 参考线    触发线              强制线
```

### 常用阈值速查

| 场景 | 阈值 | 理论 |
|------|------|------|
| 工作记忆项 | 7±2 | 米勒定律 |
| 分层容量 | 5/15/50/150 | 邓巴数字 |
| 重复触发 | 3 次 | 三次法则 |
| 缓存命中率 | > 90% | 经验值 |
| API P99 | < 1s | SRE |
| 重试次数 | 3 次 | 三次法则 |
